# Hugo Preise – Installer (Windows)

1. **[HugoPreise-Installer.zip herunterladen](https://github.com/TMgithub-ctrl/hugo-preise/raw/main/installer/HugoPreise-Installer.zip)**
2. ZIP entpacken
3. `Hugo Preise installieren.bat` doppelklicken
4. Minecraft-Instanz (Fabric, 26.2) auswählen → **Installieren**

Der Installer lädt immer die neueste Mod-Version aus diesem Repo, installiert bei Bedarf die Fabric API
(von Modrinth) und deaktiviert alte Versionen der Mod. Den Fabric Loader selbst installiert er nicht.

Warnt Windows beim Start: „Weitere Informationen“ → „Trotzdem ausführen“. Die `.ps1` ist reiner Text und
kann vorher mit dem Editor angeschaut werden.
